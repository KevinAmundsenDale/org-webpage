Sammenheng 1.4.0

- Skjul og vis menyen øverst for å gi kartet mer plass. Søk med / åpner menyen igjen.
- Dra skillelinjen ved temadetaljene for å gjøre definisjonene bredere og lettere å lese. Skillelinjen støtter også piltaster og Home/End. Menyvalg og panelbredde huskes lokalt og tilpasses vindusstørrelsen.
- Klikk på tom bakgrunn for å lukke detaljpanelet og beholde temafokus. Dobbeltklikk på tom bakgrunn for også å fjerne temafokus og markering; fagområde og terskel beholdes.
- Når detaljpanelet er åpent, setter et vanlig venstreklikk på en node det nye temaet i fokus og viser dets definisjon. Hold og dra for å flytte noden uten å bytte fokus eller definisjon.
- Ulagrede notater beskyttes fortsatt ved bytte av tema og lukking av panelet.
- Faginnhold 3 med 157 temaer, praksiseksempler til alle temaer og 12 246 forbindelser følger fortsatt med. Egne lagrede endringer beholdes.

Windows: last ned Sammenheng-1.4.0-win-x64.exe, eller bruk «Hjelp → Se etter appoppdateringer» i appen. Mac: last ned Sammenheng-1.4.0-mac-universal.dmg og dra appen til Programmer. ZIP-, YAML- og blockmap-filene brukes av oppdateringssystemet.

Installasjonsfilene er fortsatt usignerte fordi signeringsidentiteter ikke er opprettet ennå. Windows og macOS kan derfor vise sikkerhetsvarsler. Automatisk appoppdatering på Mac krever en signert utgave; denne Mac-utgaven oppdateres ved å laste ned en ny DMG. Oppdatering av faginnhold fungerer separat i appen.
